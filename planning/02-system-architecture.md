# 02 — System Architecture

## Constraints (from user)

- **No manual editing.** All editing is programmatic Python.
- Input to the engine: audio file path(s) + a JSON "direction sheet"
  describing per-segment effects (animation, text overlay, tension, color
  grade, camera motion, sound fx, etc.).
- JSON is generated by **Claude Opus** from a topic/script.
- Stock footage from **Pexels**.
- Voiceover via **Google Gemini TTS** (Google AI Studio / Gemini API).
  Decided after the user validated AI Studio output quality. Emotion is
  steered by **natural-language scene + delivery prompts per segment**
  (the AI Studio "scene" / "sample context" fields are not discrete API
  params — they are prompt text; see [06-voice-and-timing.md](06-voice-and-timing.md)).
  ElevenLabs is **dropped** (cost; Gemini quality judged sufficient).

## Pipeline

```
Topic
  → Claude Opus   (script + full video JSON + per-segment JSON,
                    incl. tts_scene / tts_delivery per segment)
  → Gemini TTS    (one call per segment: scene+delivery prompt → mp3/wav)
  → Forced Aligner(known script text + audio → exact word timestamps)
  → Python Video Engine (reads JSON, pulls Pexels clips, renders)
  → Final MP4
```

## Tech Stack

| Concern | Library |
|---------|---------|
| Clip assembly, zoom, cuts | MoviePy |
| Text rendering (custom fonts, per-frame) | Pillow |
| Color grading (LUT/.cube), audio mux | FFmpeg |
| Background-music ducking under voice | Pydub |
| Motion / advanced FX | OpenCV |
| Voiceover generation | **Google Gemini TTS** (`google-genai` SDK) |
| **Word-level timing** | **Forced alignment** — WhisperX / whisper-timestamped / Montreal Forced Aligner (NOT plain transcription) |
| Audio mastering (loudness, de-ess, comp) | Pydub + ffmpeg `loudnorm` |
| Stock footage | Pexels API |

## Components to Build (in Claude Code)

1. **JSON schema** — video-level + segment-level (see [04-json-schema.md](04-json-schema.md)).
2. **Schema validator** — reject/repair malformed Claude output before render.
3. **Claude Opus prompt** — topic → script → full JSON, incl. per-segment
   `tts_scene` + `tts_delivery` strings.
4. **Gemini TTS module** — assembles `Scene: … Delivery: … Say: <line>`
   prompt per segment, fixed `voice_name` for the whole video, one call per
   segment → per-segment audio. Multi-take + auto-select option.
5. **Forced-alignment module** — aligns the *known* segment text against its
   audio → frame-accurate per-word timestamps. This is what drives all
   word-by-word / emphasis text animation. (See [06-voice-and-timing.md](06-voice-and-timing.md).)
6. **Audio mastering stage** — per-segment loudness normalize (~-16 LUFS for
   YouTube), de-ess, gentle compression, engineered silence/pacing gaps.
7. **Pexels fetch module** — primary + backup query, anti-repetition, B-roll
   diversity (close-ups / textures / environment / slow-mo / objects).
8. **Python rendering engine** — core: reads JSON, applies the 10 variation
   layers per segment, composites, exports MP4.
9. **LUT color-grading integration** — FFmpeg `.cube` LUT pipeline.
10. **Music ducking system** — Pydub volume envelope keyed to voice loudness.
11. **Sound FX trigger system** — pre-built FX library, JSON-tag triggered.
12. **Metadata stage** — thumbnail (1280×720) + title variants /
    description / tags / chapters (gap G2, [08](08-risk-gaps.md)).
13. **YouTube upload module** — Data API v3 `videos.insert` via OAuth 2.0
    (not an API key); sets title/desc/tags/thumbnail + "altered content"
    label; uploads `private` by default, optional publish/schedule.
    **Plug-and-play & non-blocking:** the render ALWAYS writes the finished
    video + thumbnail + metadata to `output/<slug>/` locally and the run
    succeeds on that alone. Upload is a *separate best-effort step* after
    the local save — if YT creds are missing or upload fails, the local
    copy is kept, the error is logged to `render_manifest.json`, and the
    run still exits success. The local file is never deleted or gated on
    upload.

### Suggested build order

1. JSON schema + validator (the contract everything depends on).
2. Gemini TTS module + forced-alignment module (voice + timing — the
   foundation the visuals sync to).
3. Python rendering engine skeleton (ingest JSON → MP4 with synced audio).
4. Pexels fetch + anti-repetition.
5. Text rendering driven by forced-alignment word times.
6. Camera motion + cut rhythm.
7. LUT color grading + always-on FX (grain/vignette).
8. Sound FX + music ducking + mastering.
9. Claude Opus prompt + end-to-end run on the sample case.

## Asset Library (must be prepared)

- Fonts: aggressive / clinical / whisper / reveal / handwritten.
- LUTs (`.cube`): cold_isolation, threat, clinical, surveillance, memory,
  interrogation, revelation, warm_comfort, etc.
- Music library: tension drone, heartbeat, strings ostinato, piano, sub-bass.
- SFX library: whoosh, thud, bass drop, glitch, heartbeat, breath, tinnitus,
  static, match strike, door close, phone vibrate, camera shutter.
